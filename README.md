# 课间 · Kejian

轻量、离线的 Android 课表助手：本节课、下节课、调课、三类定时提醒和原创小桌宠。当前测试版本 **0.3.0 / versionCode 4**，包名 `cn.kejian.app`。

源码与原创“小团”采用 [MIT](LICENSE)；第三方组件保留各自许可，见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。公开仓库只包含合成测试数据，不包含用户真实课表或签名密钥。

## 安装与使用

从本仓库 Releases 获取 APK，Android **8.0 / API 26** 起可用；目标 API 35。界面使用设备的 Android System WebView，建议更新后使用。

首次启动为空课表，并使用手机日期。右上角“＋”选择课表文件，查看自动识别汇总，补充关键缺失或排除不确定项，确认后保存。课程卡只显示已有地点和时刻；无完整时间的课程不参与“本节课”计算。调课将目标日期映射到来源日期的原课表；不会递归叠加调课。确认替换整份课表会清除旧调课规则。

Android 13+ 的通知许可和 Android 12+ 的精确闹钟许可分别确认。拒绝后仍保存记录；精确闹钟未允许时提醒可能延后。重启、升级或系统时间/时区变化后重新计算未来提醒。强行停止、厂商省电、通知渠道关闭、免打扰或设备关机可能影响提醒，过去的提醒不会开机补发。

数据保存在应用私有 SharedPreferences；当前没有账号、云同步、系统备份或数据导出。卸载会删除数据。官方发布 APK 使用同一发行证书及递增版本号，覆盖安装可保留数据；自行编译使用不同签名时不能覆盖官方版本。

## 用户导入课表

支持 **XLSX、UTF-8 CSV、JSON**，全部在本机解析。旧 XLS 请在 Excel/WPS 另存为 XLSX；尚不支持 PDF 或图片课表。

XLSX 默认“选择文件 → 自动识别 → 汇总预览 → 确认”。可识别：

- 中英文日期列表，以及星期/周次列表；标题前可有空白行和说明，字段列可换序。
- 星期横排或竖排的课程网格、纵向跨节合并、按周多工作表。
- 有明确标签或可确定分组的混合课程文本；同格多门课保留各自周次和地点。
- 明确范围、离散周、单双周；独立节次钟点表，及课程自身标注的时间范围。

说明、空白、作息页列出处理结果；无法识别的非空页需高级映射或明确排除。合并页脚不作为课程。缺地点留空；缺钟点集中确认保留无时间。跨星期合并、复杂周次附注或时间冲突须补齐、修改或排除。重复视图可集中选择保留的工作表，不会自动认定哪份正确。高级编辑保留来源原文、字段映射和逐条排除。

文件写明完整整周日期区间时可直接生成日期。文件内一致的“第N周 + 明确星期一日期”可计算并展示首周锚点。缺少可靠日期锚点时由用户填写第1周星期一；只有单双周或未写周次时需明确学期周数。**不会按学校默认值猜学期起始日或节次钟点。** 每个已提交课程实例保留原工作表、单元格及文本来源；格式等价的相同实例去重并保留多个来源。

XLSX ≤5 MB，1–20 张工作表，每张≤2000行/40列，≤1000课程块，展开≤2000节。ZIP 单项≤8 MB、解压总量≤32 MB，并检查路径、重复项和CRC。公式不执行、不采用缓存值；宏、外部链接、加密、ZIP64及不支持的压缩方式会拒绝。解析目前在主线程；颜色规则和任意学校排版不能保证识别。

CSV/JSON 按具体日期导入，≤2 MB、1–2000条。必填 `date`（YYYY-MM-DD）、`name`，可选 `location`、`start`、`end`（HH:mm）。JSON 可为数组或 `{ "courses": [...] }`。合成示例见 [prototype/examples](prototype/examples)。

```csv
date,name,location,start,end
2026-10-12,示例课程,示例教室,09:00,10:00
2026-10-13,另一门示例课程,,14:00,15:00
```

## 隐私与边界

App 无网络、悬浮窗或广泛存储权限；只通过系统文件选择器读取所选文件。不上传课表，不调用外部模型，不执行文件中的代码。原始文件在内存解析，提交后保存规范化课程和必要的来源文本。桌宠只接受PNG或受限数据ZIP，不接受脚本、HTML、SVG和外部URL。

公开历史从审核过的干净目录初始化。真实课表、个人截图、私人测试结果、个人绝对路径、账号凭据、签名材料及Codex官方宠物资源均不在仓库中。请勿把真实课表或学号作为 Issue、PR 或测试样本公开提交；报告导入问题时使用合成/脱敏最小复现。

## 自定义桌宠与 agent 制作

点击“换个小伙伴”，选择 PNG 或 ZIP，预览后确认；取消保留原桌宠，可恢复原创“小团”。默认和示例资产均为项目原创，见 [素材来源](prototype/examples/ASSET_PROVENANCE.md)。完整格式、agent制作步骤和校验命令见 [docs/PET_FORMAT.md](docs/PET_FORMAT.md)。此格式是课间自己的轻量协议，与 Codex/ChatGPT Pets 格式不同。

## 开发与构建

运行时前端依赖 ExcelJS **4.4.0**，已固定并随项目离线提供。浏览器开发预览可在 `prototype` 中运行 `python3 -m http.server 8765 --bind 127.0.0.1`，打开本机地址；原型演示模式不等于Android提醒。

构建需要 Python **3.10+**、JDK **21**、你已同意许可并安装的 Android SDK **platform 35 / build-tools 35.0.0**。仓库不分发 SDK，也不自动接受许可。当前轻量构建脚本在 macOS 验证，Linux路径可配置；Windows、完整Gradle构建尚未验证。Gradle配置作为迁移入口提供，没有wrapper。

设置以下环境变量到你自己的目录：`KEJIAN_ANDROID_SDK`（或 `ANDROID_SDK_ROOT`）、`KEJIAN_JAVA_HOME`（或 `JAVA_HOME`）、`KEJIAN_SIGNING_DIR`。签名目录应位于仓库之外，含 `kejian-release.p12`（PKCS12，alias `kejian-release`）和 `password.txt`；使用自己的私钥，限制目录/文件访问权限，不提交到Git。

```sh
python3 android-app/tools/build_apk.py
```

脚本同步前端资源，执行aapt2、javac、D8、zipalign、apksigner并验证签名，产出 `dist/kejian-0.2.1.apk`。只同步资源时运行 `python3 android-app/tools/prepare_assets.py`；可生成单文件浏览器演示：`python3 prototype/tools/build-preview.py`。生成资源、构建缓存和签名材料被 `.gitignore` 排除。

## 测试与已验证范围

解析与DOM模拟测试使用 Node **26+**；DOM测试依赖 `jsdom 30.1.2`，仅用于测试，不进入APK。

```sh
python3 android-app/tools/prepare_assets.py
npm ci --prefix .test-deps
node tools/test.cjs
python3 tools/check_public.py
```

Java原生逻辑测试可运行 `python3 tools/test_native.py`，使用上述JDK环境变量。

当前公开合成回归：47项通用识别检查（29个独立XLSX及格式扰动）、31项既有Excel检查、23项课程/宠物包检查、19项DOM与原生桥模拟。原生时间/通知状态15项、有界解压31项检查通过。发布APK的编译、ZIP CRC、资源一致性、签名v2/v3、包名与版本核验通过。

另在本机对一份用户授权原文件完成15项结构/解析与5项DOM流程回归，原文件及其结果未公开。用户报告0.2.0在手机成功导入；这只验证该次导入完成，不能扩展为字段、周次和时间全面正确。0.2.1新增修复尚未得到新的真机验收。

DOM模拟不验证手机排版、软键盘、SAF/WebView兼容性、进程退出后的真实存储或原生后台通知。仍需覆盖升级、通知/闹钟授权、后台触发、重启恢复、跨时区和厂商省电策略的设备验收。合成测试通过不代表任意Excel都适用。

## 0.3.0 测试版：锁屏课程卡片

右上角＋ → 锁屏课程卡片，可启用静音系统通知，并单独选择允许锁屏显示课程详情。默认关闭功能、隐藏锁屏课程详情。首次主动启用才按需请求 Android 13+ 通知权限；拒绝后提供系统设置入口，课表不受影响。关闭会取消卡片和后续更新。点卡片进入应用。

本节课、下节课和地点来自已确认的日期课程及原有单层调休映射；周次与校历仍由原导入逻辑展开。不完整时间不会被猜测，缺地点不显示。以同一个通知 ID 更新，使用系统大文本样式，不响铃、不振动。

课表变更、回到前台、重启、升级、系统时间或时区变化，以及课程起止与跨日重新计算。切课使用不唤醒设备的非精确 RTC 闹钟，10 分钟调度窗口，省电、休眠或厂商限制下可能更晚；不额外请求精确闹钟权限。原作业/活动提醒的授权和调度规则继续保留。

通知权限、课程渠道及用户系统锁屏设置是前提；系统可以隐藏卡片或内容、允许划走通知。跨厂商布局与永久常驻不保证，本功能不是 AOD。没有悬浮窗、全屏意图、前台服务或亮屏保活。

本次为待验收测试 APK，未自动公开发布。测试及设备验证范围见 [验证报告](docs/LOCKSCREEN_TEST_REPORT.md)。
